# AIVORA — AI Student Hub

AIVORA is an AI-powered student productivity and learning platform designed to bring study tools, AI assistance, planning, and learning progress into one place.

## ✨ Features

- 🧠 AI Quiz Generator
- 📝 AI Notes Generator
- 🤖 AI Study Buddy
- 💻 AI Code Helper
- 📚 AI Exam Prep Mode
- 🎯 Study Planner
- ⏱️ Study Timer & Study History
- 🔥 Study Streak Tracking
- 📊 Learning Progress Dashboard
- ⭐ AIVORA XP & Level System
- 🏆 Achievements & Performance Tracking
- 👤 Personalized Student Profile
- 🧮 CGPA Calculator
- 📈 Quiz Performance Analytics

## 🤖 AI-Powered Learning

AIVORA uses AI to help students with:

- Generating study notes
- Creating interactive quizzes
- Explaining concepts
- Preparing for exams
- Solving programming-related questions
- Providing personalized study assistance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Gemini AI
- Cloudflare Workers
- LocalStorage
- Responsive Web Design

## 📊 Student Progress System

AIVORA includes a personalized learning system that tracks:

- Quiz activity
- Notes generated
- Coding activity
- Completed tasks
- Study time
- Study streak
- XP and levels
- Quiz performance
- Achievements

## 🎯 Purpose

The goal of AIVORA is to create a single, simple and intelligent workspace where students can study, practice, plan, and track their academic progress.
